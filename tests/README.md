# LunaCycle Automated Test Suite

A standalone, isolated testing layer for the LunaCycle web application.
**This suite does not modify the application.** It only reads and exercises the
running app. If a test fails, the failure is recorded and reported — never fixed
by editing LunaCycle.

## Requirements

- Node 18+
- The test-only packages are installed as dev dependencies:
  - `@playwright/test`
  - `@axe-core/playwright`
- Playwright browser binaries: run `npx playwright install chromium` once.

## Running the suite

From the repository root:

```bash
# 1. (once) install browsers
npx playwright install chromium

# 2. run the full suite (auto-starts the dev server on :5173)
npx playwright test --config=tests/config/playwright.config.js

# 3. generate the human + machine-readable summary
node tests/helpers/generate-summary.mjs
```

If the dev server already runs on another port, set it:

```bash
LUNA_BASE_URL=http://localhost:3000 npx playwright test --config=tests/config/playwright.config.js
```

## Running a single category

```bash
npx playwright test --config=tests/config/playwright.config.js tests/e2e/
npx playwright test --config=tests/config/playwright.config.js -g "TC-SC-004"
```

## Authenticated tests (Health Tracker)

The Health Tracker is gated behind login. Tests that require an authenticated
session are marked **BLOCKED** unless a saved auth state is provided.

To enable them, log in once through the app and save storage state:

```bash
npx playwright codegen --save-storage=test-results/auth/storageState.json http://localhost:5173/login
```

Then run:

```bash
LUNA_STORAGE_STATE=test-results/auth/storageState.json npx playwright test --config=tests/config/playwright.config.js tests/e2e/sessionC-tracker.spec.js
```

Without a storage state, tracker CRUD tests report BLOCKED (not FAIL) — this is
intentional and not a bug in LunaCycle.

## Output

```
test-results/
  latest/
    results.json        # Playwright JSON report (machine-readable)
    summary.json        # Executive summary (generated by generate-summary.mjs)
    report.html         # Human-readable summary
    html/               # Full interactive Playwright HTML report
    junit.xml           # CI-friendly results
    artifacts/           # Failure screenshots / traces / videos
  historical/           # (copy latest/ here to compare runs)
  failures/              # (copy failed-run artifacts here)
```

## Test case IDs

Every spec title begins with a unique ID (`TC-SC-001`, `TC-NAV-002`, …).
The full designed matrix lives in `tests/fixtures/test-cases.json`.

## Categories

| Prefix | Area |
|--------|------|
| TC-NAV | Navigation |
| TC-SC  | Symptom Checker |
| TC-PT  | Period / Health Tracker |
| TC-CE  | Condition Explorer |
| TC-PS  | Product Science |
| TC-A11Y| Accessibility |
| TC-PERF| Performance |
| TC-STAB| Stability |
| TC-ERR | Error & resilience |
| TC-SEC | Security-oriented functional checks |

## No-fix policy

This suite never edits LunaCycle. Failures are documented in the report.
