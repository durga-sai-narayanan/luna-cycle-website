# Test Results

This directory holds generated test output. It is **not** application data and is
kept separate from the LunaCycle database.

- `latest/` — most recent run (summary.json, results.json, report.html, html/, artifacts/)
- `historical/` — copy a run here to compare against future runs
- `failures/` — copies of artifacts from failed runs for triage

Do not commit real personal health information here. The suite uses synthetic
fixtures only.
